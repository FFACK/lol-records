# v0.3.1 排版修复

2026-11-19，根据用户宽屏截图修复。

- 主体最大宽度设为 1280 DIP，宽屏居中；头部卡片、搜索框、双栏和缓存状态共用同一水平边界，避免姓名和 KDA 被拉到两端。
- 详情宽度达到 840 DIP 使用 82 DIP 高的紧凑行：身份、段位徽章、技能/符文、装备、数据按列排列；更窄时使用 106 DIP 高的分层行，经济和技能错开。
- 点击区域和图标悬停区域使用与绘制相同的布局计算。
- 原生标签的非客户区背景与卡片/页面一致，消除白色横线；搜索输入移除系统边框，由统一圆角底板承载。

`cargo test --offline` 的 15 项测试、Clippy（拒绝警告）、打包通过。新增测试检查 780 至 3440 DIP 窗口的居中边界，以及详情宽度 380/397/640/839/840/897 DIP 下所有装备、技能、符文、段位图标不相交、不越界。

EXE 1,675,264 字节，低于 2 MiB。新版已启动。窗口截图工具返回 `window capture timed out`，本次未通过工具完成视觉验收；没有将几何测试当作截图验收。
