# v0.2.6 头部与交互调整

## 变更

- 头部改为圆角信息卡片，召唤师名、等级段位、同步状态分别分层排列；随窗口大小和 DPI 调整布局。
- 刷新、回到自己、更新按钮使用 Direct2D 绘制圆角、悬停、按下、禁用及键盘焦点状态，保留原生按钮的键盘与无障碍语义。绘制不可用时保留原生按钮。
- 本人身份由当前进程成功同步的登录账号确定。查看其他玩家时出现「回到自己」；刷新当前玩家不改变查看对象，回到自己重新同步当前登录账号。
- 战绩行、有效玩家名称和可用按钮显示手型光标；玩家名称悬停有背景反馈。无有效 PUUID 的名称不显示链接色。点击详情空白处不再错误提示玩家标识缺失。
- 同步时禁用刷新与返回，更新时也禁用返回；滚动、切换详情清除名称悬停状态。

## 验证

2026-11-18，Windows x64：`cargo check --offline`、Clippy（拒绝警告）、9 项单元测试通过。完整安装包构建通过，便携 EXE 1,572,864 字节（1.50 MiB），安装包 11,802,334 字节。

新版已启动，Windows 无障碍树确认账号、段位、我的近期战绩、同步期间禁用的刷新按钮和 1,036 张缓存就绪状态正常出现。窗口截图采集返回 `FrameArrived timed out`，本次未完成视觉截图验收，也未完成授权后的在线玩家跳转与返回端到端验收。未将编译通过作为这些交互的实测通过。
