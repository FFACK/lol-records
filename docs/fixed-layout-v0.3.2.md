# v0.3.2 固定布局

2026-11-19。

- 主体固定为 1200 DIP，详情区域固定为 817 DIP。窗口放大只改变水平留白，不拉伸内容，也不切换排版。
- 删除宽窄两套玩家行布局，统一使用 82 DIP 高的紧凑行。名字、段位、技能、符文、装备、数据列保持固定位置；绘制、点击和悬停共用固定坐标。
- 初始窗口宽度为 1240 DIP，最小窗口宽度为 1220 DIP（含窗口边框），防止压缩固定内容。调整高度只改变可见行数，超出部分纵向滚动。DPI 缩放仍按系统设置正常生效。
- 15 项测试和 Clippy（拒绝警告）通过。布局回归检查不同窗口宽度下主体宽度相同，并比较不同视口下每个图标的坐标及行高度完全一致，同时验证图标不相交、不越界。
