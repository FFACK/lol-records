可以查什么

账号与段位

查看当前登录账号、召唤师等级、单双排和灵活排位段位。

近期战绩

国服 LCU 实测返回最近 20 场，后续同步会合并到本地历史。

单局详情

查看双方击杀、死亡、助攻、补刀和装备。英雄和装备使用中文名称，近期战绩支持英雄头像。

首次使用

  1. 从 GitHub 发行版下载安装包，或将便携 EXE 保存到你有写权限的目录。
  2. 登录国服英雄联盟大厅，打开工具即可自动连接并同步。
  3. 若 Windows 弹出用户账户控制提示，确认后开始同步。取消后仍可查看已缓存的数据。

关闭游戏后可以查看已同步的历史。加载未缓存的单局详情需要保持客户端在线，可能再次请求授权。

怎么更新

在工具里更新。 启动时会在后台检查 GitHub 正式发行版。出现「更新到」按钮后，点击即可下载并验证签名，随后替换程序并重启。

手动更新。 打开 GitHub 发行版，关闭正在运行的工具，用新版 EXE 替换旧文件。本地战绩缓存会保留。
